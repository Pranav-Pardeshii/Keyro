Biometric Methodology & Protocol

31 Temporal Latency Features

Extracted from key events on the 11-key passphrase .tie5Roanl[Return]:

  • 11 Hold Times (H.k): Duration between keydown and keyup for each key.
  • 10 Down-Down Times (DD.k1.k2): Flight time between consecutive key presses.
  • 10 Up-Down Times (UD.k1.k2): Interval between key release and next key press.

Killourhy & Maxion (2009) Experimental Protocol

Ensures zero test leakage and authentic zero-effort impostor evaluations:

  • Training Set: First 200 repetitions of genuine user ($rep \le 200$).
  • Genuine Test Set: Remaining 200 repetitions ($rep > 200$).
  • Impostor Test Set: 5 test repetitions from each of the other 50 subjects ($50 \times 5 = 250$ impostor attempts).
  • EER Definition: Operating threshold where False Accept Rate equals False Reject Rate ($FAR = FRR$).
